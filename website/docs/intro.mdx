# About this radar

The SoftServe Tech Radar is a living catalog of technologies we have evaluated in delivery: what we tried, what worked, what did not, and when to recommend them to clients.

Each entry is a markdown file under `radar/{adopt,trial,assess,hold}/` in the repository. Merging a pull request updates the published site.

## How to read the site

- **Radar** (home) — interactive four-quadrant visualization; click a blip to open its entry.
- **All entries** (`/entries`) — sortable, filterable table of every technology.
- **Entry details** (`/docs/entries/…`) — full evaluation pages generated from radar markdown under `radar/`.
- **Contribute** — see the [contributing guide](https://github.com/CoEOrg/tech-radar-evaluations/blob/main/CONTRIBUTING.md) on GitHub.

## Rings

| Ring | Meaning |
|------|---------|
| **Adopt** | Proven in our context; default where it fits |
| **Trial** | Worth real work; limited production |
| **Assess** | Worth learning; not a default yet |
| **Hold** | Avoid new work without strong justification |
